# vault 档案（模板）

> **这是模板，不是配置。** 用之前先按下面第 1 步生成本机实际内容。

## 1. 生成你自己的档案

脚本**不依赖**本文件工作 —— `vaultio.py` 运行时直接从 Obsidian 的配置文件发现库：

| 平台 | Obsidian 配置位置 |
|------|------|
| Windows | `%APPDATA%\obsidian\obsidian.json` |
| macOS | `~/Library/Application Support/obsidian/obsidian.json` |
| Linux | `~/.config/obsidian/obsidian.json` |

```bash
$PY scripts/vaultio.py vaults      # 列出本机所有库（含路径、是否存在、是否正在打开）
```

把输出抄进下面第 2 节的表格，这份档案就有用了。

## 2. 本机库清单

| 名称 | 路径 | 用途 |
|------|------|------|
| _（示例）课程笔记_ | `/path/to/your/vault` | 主战场，课程笔记 |
| _（示例）读书_ | `/path/to/reading` | 读书笔记 |

**默认写入哪个库**：本机只有一个库就用它；有多个时**问使用者这次写哪个，别自己猜**。

## 3. 推荐的库结构（约定，可按需改）

脚本和文档默认假设「一课一文件夹 + 同名主笔记」：

```
<vault>/
├── 某课程A/某课程A.md
├── 某课程B/某课程B.md
├── 某课程C/
│   ├── 某课程C.md         ← 主笔记，材料都往这里追加
│   └── imgs/              ← 配图（相对当前笔记）
└── Clippings/             ← 剪藏素材原件，只读，勿删勿改
```

**核心约定：一课一文件。** 新材料用 `insert` 追加进该课主笔记，不另开散碎文件。
例外：题解类、实验题可以独立成文件。

> 如果你的库是别的结构（比如按主题横向积累、没有明确的"一课一文件夹"），
> 按实际调整即可 —— 脚本不绑定结构，只有 `references/note-format.md` 里的写法建议
> 是照「一课一文件夹」总结的。

## 4. 素材来源

剪藏类插件（Obsidian Web Clipper、B 站字幕插件等）导入的字幕稿常见格式：
带 YAML frontmatter（`title` / `url` / `bvid` / `author`）+ `` `00:00` 文本 `` 逐行时间戳。
`extract.py` 已针对这个格式优化。

**这些原件永远不动** —— 只读、不改、不删、不移动。

## 5. 通用偏好（可替换成你自己的）

- 新建笔记可以直接写；**改动已有笔记的正文内容要先给使用者看**
- 每次写入都要备份，并明确告诉他备份在哪、怎么回滚
- 笔记中文为主时，术语保留英文原词，对比类内容爱用表格
